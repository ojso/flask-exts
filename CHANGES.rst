v0.3.1
------

Released 2026-10-11

- Improve SQLAlchemy lifecycle management, session configuration, and in-memory SQLite support.
- Add reusable modal form flows and improve two-factor authentication setup.
- Allow extensions to provide admin views for automatic registration, and clarify duplicate extension-name errors.

v0.3.0
------

Released 2026-10-07

- Add user registration, login, logout, profile management, and user-center views.
- Add email verification, email change, password reset, and recovery workflows.
- Add a SQLAlchemy-backed user store with user profiles and role management.
- Add authentication and role-based authorization.
- Add TOTP-based two-factor authentication and recovery codes.

v0.2.0
------

Released 2026-01-07

- Add an extension system with registration, dependency management, and lifecycle hooks.
- Add an admin interface with model views, CRUD operations, filtering, sorting, pagination, and data export.
- Add SQLAlchemy integration for database access, model forms, relationships, and queries.
- Add form fields, widgets, validators, and CSRF protection.
- Add email delivery and notification support.
- Add frontend plugin management and Bootstrap-based components.
- Add Babel integration for localization.
