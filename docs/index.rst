Welcome to Flask-Exts's documentation!
======================================

**Flask-Exts** is a Flask extension toolkit that brings together SQLAlchemy, Babel, forms, fields, widgets, 
and admin features to help build complete web applications faster.

Flask-Exts is mainly inspired by:

- `Flask-Admin <https://github.com/pallets-eco/flask-admin/>`_
- `Bootstrap <https://getbootstrap.com/>`_

.. _installation:

Installation
--------------

To use Flask-Exts, first install it using pip:

.. code-block:: console

   (.venv) $ pip install flask-exts
