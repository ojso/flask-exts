Flask-Exts

Composable extensions for Flask: admin views, authentication, security, forms, and database helpers.

Quick start

pip install flask-exts
from flask import Flask
from flask_exts import ExtensionManager

app = Flask(__name__)
ExtensionManager().init_app(app)

Configure the extensions you need through app.config, then start your application as usual.

Included

  • Admin views and model CRUD
  • Login, users, and role-based access
  • Forms, JSON fields, and translations
  • SQLAlchemy helpers and query utilities
