========================
Examples
========================

English / 中文
----------------
This page lists runnable examples for Flask-Exts and shows how to run them locally.
中文说明：本页面列出 Flask-Exts 的可运行示例，并说明如何在本地启动这些示例。

Download
=========

Type these commands in the terminal:

.. code-block:: bash

    $ git clone https://github.com/ojso/flask-exts.git
    $ cd flask-exts/examples
    $ python3 -m venv venv
    $ source venv/bin/activate
    $ pip install flask-exts

Run the examples
===============================

Type the command in the terminal, then go to http://localhost:5000.

simple
-----------------

.. code-block:: bash
    
    $ flask --app simple run

demo
-----------------

Default admin user is ``admin``, password is ``admin``.

.. code-block:: bash
    
    $ flask --app demo run
