## Stimulus.js 详解 ### 是什么 [Stimulus](https://stimulus.hotwired.dev/) 是 [Basecamp](https://basecamp.com/) 开发的轻量级 JavaScript 框架，是 **Hotwire** 生态的一部分。核心理念： > **HTML 才是主角，JS 只是行为层。** 不用 JS 渲染 HTML，而是给已有 HTML **附加行为**。 --- ### 核心原理 ``` ┌─────────────────────────────────────────────┐ │ HTML │ │
│ │ 0│ │ │ │
│ └──────────────────┬──────────────────────────┘ │ data-controller → 自动实例化 Controller data-action → 绑定事件到方法 data-target → 引用 DOM 元素 │ ┌──────────────────▼──────────────────────────┐ │ JavaScript Controller │ │ │ │ class Counter extends Controller { │ │ static targets = ["output"] │ │ connect() { this.count = 0 } │ │ inc() { │ │ this.count++ │ │ this.outputTarget.textContent = ... │ │ } │ │ } │ └─────────────────────────────────────────────┘ ``` **三个核心概念**： | 概念 | HTML 属性 | 作用 | |---|---|---| | **Controller** | `data-controller="name"` | 声明哪个 JS 类控制这段 DOM | | **Action** | `data-action="event->controller#method"` | 把 DOM 事件绑定到方法 | | **Target** | `data-controller-target="name"` | 让 JS 可以引用这个 DOM 元素 | **生命周期**： - `connect()` — 元素出现在 DOM 时调用 - `disconnect()` — 元素从 DOM 移除时调用 --- ### 安装 ```bash npm install @hotwired/stimulus ``` ```javascript // app.js import { Application } from "@hotwired/stimulus" const application = Application.start() // 注册 controllers import CounterController from "./controllers/counter_controller" application.register("counter", CounterController) ``` --- ### Inline Edit 示例 **完全可以做！** 这是 Stimulus 的典型场景： ```html

``` --- ### 为什么用 Stimulus 做 inline-edit 很合适 | 优势 | 说明 | |---|---| | **HTML 驱动** | 行为绑定在 HTML 上，一眼看出哪个元素可编辑 | | **零渲染** | 不需要 JS 生成 DOM，切换显隐即可 | | **渐进增强** | JS 加载前，文本正常显示，只是不能编辑 | | **复用性** | 页面上多个 inline-edit 实例互不干扰 | | **轻量** | 框架本身只有 ~10KB | --- ### 与其他方案对比 | 方案 | 大小 | 适合场景 | |---|---|---| | **Stimulus** | ~10KB | HTML 优先、Rails/Turbo 项目、渐进增强 | | **React/Vue** | 30-100KB | SPA、复杂状态管理 | | **Alpine.js** | ~15KB | 轻量交互、不需要构建工具 | | **原生 JS** | 0 | 简单场景、不想引入框架 | --- ### 一句话总结 > **Stimulus 的哲学：HTML 定义结构，CSS 定义样式，Stimulus 只负责行为。** 不渲染、不路由、不管状态，只做"给已有 HTML 加交互"这一件事。 需要我写一个完整的可运行的 inline-edit demo 吗？
